# Vite + Bootstrap Starter Template

A lightweight and fast starter template for building modern web applications using [Vite](https://vitejs.dev/) and [Bootstrap](https://getbootstrap.com/).

## 📦 Features
- ⚡ **Vite** for blazing-fast development and optimized builds
- 🎨 **Bootstrap 5** for responsive UI components
- 🛠 Easy customization via SCSS
- 📱 Mobile-first design
- 🔧 Ready for deployment

---

## 🚀 Getting Started

### Clone the repository
```bash
git clone https://github.com/phpfms/boutique_web.git
cd boutique_web
```

### Install dependencies
```bash
npm install
```

### Start development server
```bash
npm run dev
```
